How to set up
  1. Sign up at jsonbin.io (free).
  2. Create a new private bin and paste this as its content: {"v":3,"nextTabId":2,"allTabs":[{"id":1,"name":"index.html","content":"","updatedAt":0}],"deletedIds":[]}
  3. Copy the Bin ID from the bin URL (the part after /b/).
  4. Open the API Keys page and copy your X-Master-Key.
  5. Paste both values above and click Save & Sync.

Content syncs automatically. Each device keeps its own open tabs. The dropdown lists tabs from OTHER devices; deleting there removes the tab everywhere.
