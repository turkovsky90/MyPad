How to set up
  1. Sign up at jsonbin.io (free).
  2. Create a new private bin and paste this as its content: {"v":1,"tabs":[{"id":1,"name":"index.html","content":""}],"activeTabId":1}
  3. Copy the Bin ID from the bin URL (the part after /b/).
  4. Open the API Keys page and copy your X-Master-Key.
  5. Paste both values above and click Save & Sync.

If Bin ID is empty, a new private bin will be created automatically using your key.
